Jayaraj T – Digital Marketer Portfolio

This repository contains the source code for my personal portfolio website, built with **Eleventy** (11ty) and **Tailwind CSS**. The site showcases my expertise in SEO, performance marketing, social media, content strategy, and technical optimization, and includes interactive KPI widgets.

## Development Stack

- **Eleventy** – static site generator
- **Tailwind CSS** – utility‑first styling
- **Alpine.js** – lightweight interactivity
- **Chart.js** – KPI charts

## Scripts

```
npm install            # install dependencies
npm run dev            # start local dev server (eleventy --serve)
npm run build          # generate production files in ./dist
```

## Deployment

GitHub Actions automatically builds and publishes the site to GitHub Pages on every push to the `main` branch.
